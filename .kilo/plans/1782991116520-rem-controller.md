# План: RemController — управление REM-сигналом через оптопару

## Контекст

Устройство: Arduino Nano ATmega328P, Arduino framework, ArduinoJson 7.x.
Протокол: JSON-команды в `[...]`, одна на строку, Serial 115200 бод.
Существующий паттерн: каждый аппаратный модуль — класс в `.h`/`.cpp`.

## Назначение

Управление REM (Remote Enable) сигналом усилителя через оптопару (гальваническая развязка).
Пин A2 → токоограничительный резистор → светодиод оптопары.
HIGH = оптопара открыта = REM активен (усилитель включен).
LOW = оптопара закрыта = REM неактивен (усилитель выключен).

## Принятые решения

| Параметр | Значение |
|---|---|
| Формат `value` | Булево: `true` / `false` |
| Команды | Только `set_is_enable_rem` |
| Имя класса | `RemController` |
| Пин | `A2` |
| Состояние при старте | OFF (`LOW`) |

## Задачи

### 1. Создать `src/RemController.h`

Заголовочный файл с include guard и объявлением класса.

**API:**

```cpp
class RemController {
public:
    RemController();
    void begin();           // pinMode(OUTPUT) + digitalWrite(LOW)
    void enable(bool on);   // HIGH если true, LOW если false
    void enable();          // удобство: включить
    void disable();         // удобство: выключить
    bool isEnabled() const; // вернуть _enabled

private:
    static constexpr uint8_t REM_PIN = A2;
    bool _enabled;
};
```

### 2. Создать `src/RemController.cpp`

Реализация:

- Конструктор: `_enabled = false`
- `begin()`: `pinMode(REM_PIN, OUTPUT); digitalWrite(REM_PIN, LOW);`
- `enable(bool on)`: `_enabled = on; digitalWrite(REM_PIN, on ? HIGH : LOW);`
- `enable()`: `enable(true);`
- `disable()`: `enable(false);`
- `isEnabled()`: `return _enabled;`

### 3. Изменить `src/main.cpp`

#### 3a. Подключить заголовок (после строки 6)

```cpp
#include "RemController.h"
```

#### 3b. Объявить экземпляр (после строки 24, рядом с другими глобальными объектами)

```cpp
RemController remController;
```

#### 3c. Инициализировать в `setup()` (после строки 237, рядом с другими `.begin()`)

```cpp
remController.begin();
```

#### 3d. Добавить команду в `parseCommand()` (после блока `change_preset`, перед `get_preset` или в любое логичное место)

```cpp
else if (strcmp(command, "set_is_enable_rem") == 0) {
    bool value = doc["value"].as<bool>();
    remController.enable(value);
    StaticJsonDocument<128> responseDoc;
    responseDoc["status"] = "success";
    responseDoc["command"] = "set_is_enable_rem";
    responseDoc["is_enable_rem"] = remController.isEnabled();
    sendResponse(responseDoc);
}
```

## Ответ

При успехе:

```json
[{"status":"success","command":"set_is_enable_rem","is_enable_rem":true}]
```

## Не требуется

- Новые библиотеки (`platformio.ini` без изменений)
- EEPROM-сохранение (состояние сбрасывается при перезагрузке)
- Команда `get_is_enable_rem` (не запрошена)

## Валидация

1. Собрать проект: `pio run`
2. Залить на плату: `pio run --target upload`
3. Открыть Serial Monitor: `pio device monitor`
4. Отправить `[{"command":"set_is_enable_rem","value":true}]` — на пине A2 должен появиться HIGH (~5V)
5. Отправить `[{"command":"set_is_enable_rem","value":false}]` — на пине A2 должен быть LOW (~0V)
6. Проверить ответы в формате `[...]`
